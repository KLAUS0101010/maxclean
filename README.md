# MAX Clean (готовый APK)

Берёт официальный APK MAX и собирает из него один подписанный APK без сторонних трекеров.
Ничего ставить на телефон кроме самого APK не нужно (без LSPatch).

- `patch_max.py` — сам патчер (читается за 5 минут, делает 5 понятных вещей).
- `tests/test_patch.py` — тесты на «макете» приложения.
- `.github/workflows/build.yml` — сборка на GitHub: распаковка apktool → патч → сборка → подпись.
