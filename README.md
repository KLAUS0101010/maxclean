# MAX Clean

Берёт официальный APK MAX, отключает слежку (трекеры → `0.0.0.0`, заглушки отправки, встроенный переключатель аналитики), добавляет `www.max.ru` к ссылкам и собирает подписанный APK. Всё остальное в APK остаётся байт в байт как в оригинале.

- `patch_max.py`: патчер (`dex` для кода, `manifest` для манифеста).
- `graft_apk.py`: собирает результат из оригинала и только изменённых частей (dex и манифест).
- `check_manifest.py`: проверка, что пересобранный манифест не потерял ссылки на ресурсы.
- `dex_api.py`: поднимает уровень API для apktool.
- `tests/`: тесты на макете.
- `.github/workflows/main.yml`: сборка в GitHub Actions (варианты full, minimal, control).

Подробно: **INSTRUCTION-RU.md**.
